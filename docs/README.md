# Collaborative Workspace

## Совместная рабочая область с WebSocket синхронизацией

Простое и эффективное решение для совместной работы над творческими проектами в реальном времени.

## Возможности

### 🔄 Real-time синхронизация
- WebSocket соединение для мгновенной синхронизации
- Видите, кто редактирует документ
- Чат для обсуждения

### 💾 Версионирование
- Автоматическое сохранение версий
- История изменений
- Сравнение версий

### 💬 Система фидбека
- Комментарии к проектам
- Категории: сильные стороны, улучшения, вопросы, идеи
- Отслеживание статуса

### 🤖 AI-анализ
- Анализ тем и тональности
- Оценка сложности текста
- Предложения по улучшению
- Генерация идей

## Установка

### Требования
- Python 3.8+
- pip

### Шаги установки

1. Перейдите в директорию backend:
```bash
cd backend
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите сервер:
```bash
python main.py
```

Или используйте скрипты:
- Windows: `start.bat`
- Linux/Mac: `start.sh`

## Использование

1. Откройте браузер: http://localhost:8000
2. Введите своё имя
3. Создайте новый проект или выберите существующий
4. Начните писать — изменения синхронизируются автоматически

### Горячие клавиши
- `Escape` — закрыть модальные окна
- `Enter` в чате — отправить сообщение

## API Endpoints

### Проекты
- `GET /api/projects` — список проектов
- `POST /api/projects` — создать проект
- `GET /api/projects/{id}` — получить проект
- `PUT /api/projects/{id}` — обновить проект

### Версии
- `GET /api/projects/{id}/versions` — история версий
- `POST /api/projects/{id}/versions` — сохранить версию

### Фидбек
- `GET /api/projects/{id}/feedback` — фидбек проекта
- `POST /api/projects/{id}/feedback` — добавить фидбек

### Анализ
- `GET /api/projects/{id}/analysis` — проанализировать проект
- `POST /api/projects/{id}/brainstorm` — сгенерировать идеи

### WebSocket
- `WS /ws/{project_id}?user={username}` — real-time синхронизация

## PAUSE OS Collaboration Module

Встроенный модуль с 4 компонентами:

### ProjectAnalyzer
Анализирует контент проекта:
- Извлекает темы
- Определяет тональность
- Оценивает сложность
- Даёт рекомендации

### NotebookLMOrchestrator
Генерирует промпты для LLM:
- Brainstorm идей
- Расширение разделов
- Критика проекта
- Планирование коллаборации

### CriticFeedback
Управление фидбеком:
- Категоризация
- Статусы
- Реакции
- История

### CollabCoordinator
Версионирование и сессии:
- Создание версий
- Сравнение изменений
- Сессии совместной работы
- Лог активности

## Настройка

### Изменение порта
В `backend/main.py`:
```python
uvicorn.run(app, host="0.0.0.0", port=8000)  # Измените порт
```

### Изменение URL в frontend
В `frontend/app.js`:
```javascript
const CONFIG = {
    API_URL: 'http://localhost:8000',
    WS_URL: 'ws://localhost:8000/ws',
    // ...
};
```

## Развёртывание

### Локально
```bash
cd backend
python main.py
```

### На сервере
1. Установите Python и зависимости
2. Запустите: `python main.py`
3. Настройте nginx для статики (опционально)
4. Используйте systemd или supervisor для автозапуска
